# 🦴 Bone Edge Enhancement Tool — User & Technical Manual

## 1. Overview
The Bone Edge Enhancement Tool is an interactive web application designed to isolate high-frequency structural details, sharp edges, and hairline fractures in X-ray images using 2D Fourier High-Pass Filtering and CLAHE contrast normalization.
